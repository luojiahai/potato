# Potato icon

The icon keeps the product identity literal: an original potato drawing on a flat warm-gold tile. Its compact diagonal silhouette follows the familiar visual language of a system emoji without copying any vendor artwork.

## Assets

- `potato-app-icon.svg`: primary application icon
- `png/`: raster exports from 16 px through 1024 px

## Color

| Token | Value | Use |
| --- | --- | --- |
| Warm gold | `#f4b942` | Icon tile |
| Potato | `#b9653d` | Main tuber |
| Highlight | `#d88752` | Upper plane |
| Shadow | `#8f472d` | Lower plane |
| Golden brown | `#70431f` | Outline and eyes |

The gold extends the TUI accent family. Keep every color flat. Do not add gradients, faces, limbs, lettering, or extra symbols.

## Usage

Use the SVG wherever possible. The PNG exports are provided for fixed-size integrations.
